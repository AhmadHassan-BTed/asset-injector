# Changelog

## Unreleased

### Changed

- Renamed `EQOA_REPO_COLLECTION/` to `UTILITIES/` so the repository layout clearly identifies those folders as external tools and reference projects.
- Updated code and documentation references to use the new `UTILITIES` path.

### Utility Authors

The utility set is made from projects created by their original authors and maintainers. These are not presented as contributors to this repository; they are credited here for the tools, data, servers, patches, and format references they built for the EQOA ecosystem.

- [benturi](https://github.com/benturi) created `ben_eqoa_c_server`, a lightweight C server implementation for EQOA packet/server experiments.
- [rosyfiles](https://github.com/rosyfiles) created `EQOA_Addons`, Lua-based addon and helper scripts for EQOA workflows.
- [devin103](https://github.com/devin103) created `EQOA_Creator`, `EQOA-Frontiers-ISO-Patch`, and `EQOA-Prototype-Server`, covering creator tooling, ISO patching, and prototype server work.
- [Jadiction](https://github.com/Jadiction) created `EQOA-Data`, the structured data reference used for EQOA game data research.
- [DabDavis](https://github.com/DabDavis) created `eqoa-esf-tools` and `eqoa-pipeline`, tooling for ESF/CSF inspection, extraction, modification, and pipeline workflows.
- [userrnx](https://github.com/userrnx) created `EQOA-Ranix`, an EQOA utility/reference project.
- [joukop](https://github.com/joukop) created `EQOA-server` and `ESF-file-format`, server and file-format reference projects.
- [eqoa](https://github.com/eqoa) created `eqoa.github.io`, a web reference for EQOA information.
- [EQOAReturnHome](https://github.com/EQOAReturnHome) created `EQOAGameServer`, a modern EQOA game server implementation.
- [Dexr1te](https://github.com/Dexr1te) created `eqoazyc-api`, an API project for EQOA-related services.
- [Faxonation2](https://github.com/Faxonation2) created `Hagley`, an EQOA utility/reference project.
- [Randall-Adams](https://github.com/Randall-Adams) created `Kairen`, an EQOA utility/reference project.
- [unenergizer](https://github.com/unenergizer) created `OpenEQOA`, an open EQOA server/reference implementation.
- [trevormorg](https://github.com/trevormorg) created `tech-eqoakv`, an EQOA technical/reference project.
- [skulkingfox](https://github.com/skulkingfox) created `eqoa`, an EQOA reference project.
